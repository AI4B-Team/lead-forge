Comp Sources​

Used in /comps source. Each source value corresponds to a record_type on the response.

Source value (request)	Response record_type
PUBLIC_RECORD	ASSESSOR
MLS_LISTINGS	MLS_LISTING
MLS_RENTALS	RENTAL_ALT
(default — single-source)	LISTING_ALT may also appear as an auxiliary listing-source variant.

The full list of record_type values that may appear in responses: ASSESSOR, MLS_LISTING, LISTING_ALT, RENTAL_ALT. Additional listing-source variants may appear over time — treat any unrecognized value as a listing record using the LISTING_ALT shape documented in Property Object → Comp record-type variations.

Comp Days Lookback​

Convenient values accepted by /comps days: 30, 60, 90, 180, 365, 730, 1825. Use 0 for no time restriction. Other positive integers are accepted but may not align with reporting buckets.

Geographic Anchors​

US state codes accepted in state, places[].state, regionsRestriction.state, and similar fields:

AL, AK, AZ, AR, CA, CO, CT, DE, DC, FL, GA, HI, ID, IL, IN, IA, KS, KY, LA, ME, MD, MA, MI, MN, MS, MO, MT, NE, NV, NH, NJ, NM, NY, NC, ND, OH, OK, OR, PA, RI, SC, SD, TN, TX, UT, VT, VA, WA, WV, WI, WY

regionsRestriction.state also accepts "*" as a single element to indicate "no state restriction" (the default when omitted).
